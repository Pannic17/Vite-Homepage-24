7. 删除原 MenuSection 兼容层、无引用 AniButtom／HelloWorld／Three 组件、旧 GCS 专用视图、Vue 模板图标和 22 个不可达实验效果／shader 文件。删除前从 main/router 的静态及动态导入追踪确认不可达；首页使用的效果未变更。
