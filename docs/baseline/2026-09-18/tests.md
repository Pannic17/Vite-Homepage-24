## 正常冒烟

每种尺寸运行 6 项：

1. 首页标题与 canvas 存在，图片可解码，模型响应为有效 glTF 2.0，未捕获 pageerror。
2. 首页 → About → 返回首页。
3. 首页 → Works → 返回首页。
4. 首页 → Projects → 返回首页。
5. 首页即时切换中文和英文，身份文字与导航跟随变化。
6. 生产部署前缀下 Works 与 Projects 的图片全部成功解码。

这些只覆盖已存在的正常路径；HOME 测试从首页进入再返回，不证明“从外部直达时 HOME 正确”。

## 已知缺陷

每种尺寸运行 3 项：

- B01：调整尺寸应保留原文档，实际刷新。
- B02：切换中文后刷新应保持选择，实际回到英文。
- B03：GCS 地址应渲染详情结构，实际仍显示父列表。

测试先完成页面加载和前置条件，最后才标记 expected failure 并断言期望的正确行为。阶段 1/3 修复后，测试会因 unexpected pass 提醒移除标记；不得修改断言去适应旧缺陷。
